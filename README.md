# 🎬 Cinema Ticket Booking System

A full-stack cinema ticket booking application developed using Angular, Node.js, Express.js, and MongoDB.

The system is designed to manage movie browsing, cinema halls, showtimes, ticket reservations, and booking administration.

## 🚀 Features

- User authentication and authorization
- Movie browsing and filtering
- Cinema hall and showtime management
- Ticket booking and reservation management
- Booking confirmation and cancellation
- Administrative booking management

## 🛠 Tech Stack

**Frontend**
- Angular
- TypeScript

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose

**Authentication & Security**
- JSON Web Tokens (JWT)
- bcrypt
- Cookie Parser
- Input Validation

**Development Tools**
- Git & GitHub
- npm
- Nodemon

## 📌 Note

This project was developed as part of an academic software development project, demonstrating full-stack development, REST API integration, database management, and application architecture.
